# 💻 Portfólio — Luan Silva

Portfólio profissional desenvolvido para apresentar meus projetos, habilidades e conhecimentos na área de desenvolvimento web.

O projeto foi desenvolvido utilizando React, TypeScript e Tailwind CSS, com foco em responsividade, organização de componentes e uma interface moderna e intuitiva.

## 🚀 Tecnologias

- React
- TypeScript
- Tailwind CSS
- HTML5
- Git
- GitHub

## ✨ Funcionalidades

- Apresentação profissional
- Seção sobre mim
- Exibição dos meus projetos
- Tecnologias e ferramentas que utilizo
- Links para os repositórios dos projetos
- Links para minhas redes profissionais
- Design responsivo para diferentes tamanhos de tela
- Navegação entre as seções da página
- Botão para voltar ao topo

## 📂 Estrutura do projeto
